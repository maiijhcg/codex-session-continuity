# Changelog

## 0.1.0 — Windows public preview

- Portable configuration and per-user installation; no maintainer-specific paths or task IDs.
- Windows sign-in startup enabled by default, with explicit opt-out and data-preserving uninstall.
- English-first menu with Traditional Chinese, Simplified Chinese, Japanese, and Spanish translations.
- Nine language README/user-guide entry points.
- Nine language checkpoint and successor instructions; follow the saved menu language or an explicit handoffLanguage.
- Successors inherit the previous session's actual sandbox/approval settings independently of global defaults, with detailed policy verification.
- Four original illustrative README images, including an accessible text-rich feature overview.
- Local archival, attachment provenance, manual/automatic handoff, project/cwd/permission verification, and guarded recovery inherited from the tested local implementation.
- App `callerSource` compatibility and read-only endpoint health checks; candidate probe cap 128.
- Explicit release allowlist, privacy scan, checksums, and Windows regression workflow.

This preview does not install Node.js/PowerShell, change Codex permissions or model
settings, auto-trust hooks, or delete history. Licensing remains unspecified.
