Помощник для Windows: сохраняет локальную историю, готовит заметку о передаче и продолжает работу в том же проекте. Новая задача читает заметку и при необходимости обращается к доказательствам, а не получает всю переписку заново.

> [!IMPORTANT]
> Экспериментальная предварительная версия, не официальный продукт OpenAI. Локальные интерфейсы приложения могут меняться после обновления. После новой установки автоматическое продолжение приостановлено: сначала проверьте эффективное окно модели и пороги.

## Возможности

![Возможности](images/overview.png)

| Функция | Описание |
| --- | --- |
| Сохранение истории | Постепенное архивирование записанных на диск диалогов и результатов инструментов с поисковым индексом. |
| Подготовка передачи | Исходный помощник фиксирует решения, прогресс, ограничения, проверки и следующие шаги. |
| Тот же проект | Проверяются проект, каталог и разрешения; сохраняются checkout и незакоммиченные файлы. |
| Вложения | Сохраняются поддерживаемые локальные и встроенные файлы с происхождением. Сохранение не означает понимание содержимого. |

## Три шага

![Три шага](images/workflow.png)

1. Архив: локальные записи и ссылки на вложения сохраняются в фоне.
2. Подготовка: исходный помощник пишет HANDOFF.md и возвращает уникальный токен подтверждения.
3. Продолжение: после завершения исходного хода и проверок создаётся ровно одна новая задача.

## Установка в Windows

Нужны Codex Desktop с выполненным входом, Node.js 24+ и PowerShell 7+. Сохраните точный рабочий каталог как проект приложения. Создайте отдельную управляющую задачу и скопируйте UUID или ссылку; она должна отличаться от продолжаемой задачи.

Скачайте ZIP и SHA256SUMS из Releases, проверьте SHA-256 и распакуйте. Откройте PowerShell 7 в этой папке и замените шаблон ниже настоящим UUID управляющей задачи.

[Releases](https://github.com/maiijhcg/codex-session-continuity/releases)

```powershell
pwsh -NoProfile -File .\install.ps1 -OwnerThreadId "PASTE_MANAGEMENT_TASK_UUID" -WithIntegration
```

Папка по умолчанию — `%LOCALAPPDATA%\CodexSessionContinuity`. Автозапуск при входе текущего пользователя в Windows включён при установке: после перезагрузки и входа процесс работает в фоне без прав администратора. Это не системная служба до входа. Автоматические передачи изначально приостановлены, а последующие входы сохраняют выбранное состояние.

`-NoStartup` отменяет регистрацию автозапуска, `-NoStart` откладывает запуск, `-InstallDir` и `-CodexHome` задают каталоги, `-SoftLimit`/`-HardLimit` — пороги. Без `-WithIntegration` настройка hook и инструкций откладывается. Hook проходит обычную проверку доверия Codex, без автоматического одобрения.

## Ручное управление

![Ручное управление](images/control.png)

| Клавиша | Действие |
| --- | --- |
| **1** | Включить автоматическое продолжение |
| **2** | Приостановить автоматику; архивирование продолжается |
| **3** | Обновить состояние процесса, соединения и запросов |
| **4** | Явно выбрать одну задачу по номеру, UUID или полной ссылке |
| **5** | Выбрать и сохранить язык меню |
| **0** | Выйти, не изменяя переключатель |

Сначала выберите 3 и проверьте процесс, свежий heartbeat и соединение, затем 1 или 4. Активные задачи идут первыми, далее — по недавней активности. Очередь не означает завершение; повторный выбор использует существующий ожидающий запрос.

По умолчанию меню английское; доступны английский, традиционный и упрощённый китайский, японский и испанский. Документация также есть на русском, французском, корейском и немецком; эти языки меню пока не поддерживаются. Заголовки задач, история и техническая диагностика остаются в исходном языке. 5 сохраняет язык, `-Language` меняет его только для текущего запуска.

```powershell
.\Codex-Session-Continuity.cmd -Language en
pwsh -NoProfile -File .\manual-switch.ps1 -Action Status -Language en -Json
```

## Пороги и ограничения

Примерные значения по умолчанию: мягкий 500 000 и жёсткий 920 000 токенов; они подходят не всем моделям. Мягкий порог требует наблюдаемого пересечения снизу при непрерывном мониторинге. Если при запуске/возобновлении он уже пройден, пропущенное событие не воспроизводится: применяется жёсткий порог текущего использования. Нативное сжатие может использовать иной счётчик или меньшее окно. Настройки модели и ёмкость контекста не меняются.

## Данные и безопасность

В `archive/`, `notes/`, рабочих `assets/`, SQLite, конфигурации и журналах есть приватные данные. Не загружайте их на GitHub. Утилита не добавляет отдельную телеметрию или облачный клиент; обычные сообщения и создание задач Codex по-прежнему используют ваш сервис и аккаунт.

История и медиа не удаляются автоматически. Следите за диском и делайте отдельные резервные копии. Нет встроенного шифрования, OCR или транскрипции; удалённые вложения не скачиваются скрытно. Пауза не отзывает отправленные операции, а остановка процесса прекращает и новое архивирование.

## Ожидание и ошибки

`waiting_handoff` ждёт исходную задачу; `soft_expired` не повторяет устаревший мягкий сигнал; после `checkpoint_interrupted` повторный выбор решает пользователь. При `checkpoint_uncertain`/`creation_uncertain` сначала проверьте результат, не отправляйте запрос вслепую. Несовпадение проекта или разрешений останавливает процесс без смены каталога и повышения прав.

```powershell
node .\cli.mjs status
node .\cli.mjs tasks
node .\controller.mjs resolve "PASTE_TASK_UUID"
```

## Запуск, обновление и удаление

Выполняйте команды ниже в установленной папке. Перед обновлением остановите процесс, сохраните резервную копию всей приватной папки и переустановите в то же место. Удаление интеграции сохраняет программу, настройки, записи, заметки и вложения; задачи Codex не удаляются.

```powershell
pwsh -NoProfile -File .\install-startup.ps1
pwsh -NoProfile -File .\install-startup.ps1 -Remove
pwsh -NoProfile -File .\stop.ps1
pwsh -NoProfile -File .\restart.ps1
pwsh -NoProfile -File .\uninstall.ps1
```

## Язык инструкций и наследование прав

Уведомления исходной сессии и начальные инструкции новой доступны на девяти языках: `en`, `zh-Hant`, `zh-Hans`, `ja`, `es`, `fr`, `ko`, `ru`, `de`. По умолчанию используется английский либо язык, сохранённый пунктом 5. Для новой установки добавьте `-HandoffLanguage ru`. В существующей остановите процесс, добавьте `"handoffLanguage": "ru"` в `config.json` и перезапустите. Обновление сохраняет настройки; удаление свойства возвращает связь с меню. Временный `-Language` не меняет фоновые сообщения. Во время одной передачи язык фиксирован; исходные названия, пути, команды, права и коды подтверждения не переводятся.

Новая сессия автоматически наследует фактические sandbox и подтверждения предыдущей сессии, а не глобальные настройки или права управляющей задачи. Источник только для чтения остаётся таким даже при глобальном Full access. Используется штатное наследование Codex: источник проверяется перед отправкой, область записи, сеть и профиль — после создания. При изменении источника данные перечитываются; неизвестный результат или расхождение останавливают процесс с сохранением ID. Права не повышаются, глобальные настройки не меняются, дубликаты не создаются. Если источник только для чтения не может сохранить HANDOFF.md, требуется обычная процедура разрешений пользователя. Старая локальная версия автоматически не обновляется.
